Этот код создает "картину по номерам" на основе загруженного изображения, разделяя цвета для главных объектов и фона и генерируя контурное изображение с номерами цветов. В результате создается комбинированное изображение и текстовый файл с перечнем основных цветов.

## Требования

- Python 3.7 или выше
- Установленные библиотеки:
    - OpenCV (`cv2`)
    - NumPy
    - Torch
    - Torchvision
    - Matplotlib
    - Pillow

## Установка

Для установки зависимостей выполните:

`pip install -r requirements.txt`

## Параметры

- **NUM_COLORS_MAIN**: Количество цветов для главных объектов (по умолчанию 15).
- **NUM_COLORS_BACKGROUND**: Количество цветов для фона (по умолчанию 7).
- **MIN_AREA_CONTOUR**: Минимальная площадь контуров, отображаемых на итоговом изображении.
- **MAX_DIMENSION**: Максимальный размер изображения для обработки.
- **MEAN_SHIFT_RADIUS и MEAN_SHIFT_COLOR**: Настройки сглаживания фона.
- **FONT_SIZE, FONT_COLOR, FONT_THICKNESS**: Параметры текста для номеров цветов.
- **CONTOUR_COLOR и CONTOUR_THICKNESS**: Цвет и толщина контуров.

## Использование

1. Загрузите изображение в том же каталоге, где находится скрипт, или укажите путь к изображению в строке `create_paint_by_numbers("test.jpg")`.
2. Запустите скрипт. Он создаст три изображения:
    - Оригинальное изображение.
    - Версия "раскраска по номерам".
    - Контурное изображение с номерами цветов.
3. Результаты сохраняются в папке `./saved`:
    - `combined_image.jpg` — изображение с основными и фоновыми цветами.
    - `blank_image.jpg` — контурное изображение с номерами цветов.
    - `colors.txt` — текстовый файл с RGB-кодами цветов.

## Пример

При запуске кода:

`python app.py`

вы получите изображения и файл со списком основных и фоновых цветов в формате RGB.

## Описание процесса создания изображения

1. **Чтение и подготовка изображения**  
    Изображение загружается и приводится к формату RGB, после чего его размер масштабируется до заданного максимального размера (`MAX_DIMENSION`) для повышения эффективности обработки.
    
2. **Сегментация изображения**  
    Используется предобученная модель `DeepLabV3` с архитектурой `ResNet101`, предназначенная для сегментации изображений. Модель выделяет области, содержащие основные объекты, и создает маску этих объектов.  
    Маска увеличивается или уменьшается под размер оригинального изображения и используется для разделения изображения на два компонента:
    
    - **Основные объекты** — области, выделенные моделью как значимые.
    - **Фон** — оставшиеся части изображения.
3. **Сглаживание фона**  
    К фоновому изображению применяется фильтрация `pyrMeanShiftFiltering`, чтобы сгладить его и упростить палитру, что облегчает дальнейшую кластеризацию.
    
4. **Кластеризация цветов**  
    Используется алгоритм K-means для кластеризации цветов:
    
    - **Основные объекты**: цвета кластеризуются до заданного числа `NUM_COLORS_MAIN`.
    - **Фон**: цвета кластеризуются до заданного числа `NUM_COLORS_BACKGROUND`.
    
    Кластеризация преобразует множество оттенков в ограниченный набор основных цветов. Центры кластеров представляют собой усредненные цвета, которые затем заменяют все пиксели внутри каждого кластера.
    
5. **Создание изображения "раскраска по номерам"**  
    После кластеризации полученные центры цветов (основные и фоновые) используются для создания нового изображения. Пиксели заменяются цветами ближайшего к ним центра, что создает эффект "раскраски по номерам".
    
6. **Создание контурного изображения с номерами цветов**  
    Контурное изображение создается для обозначения границ каждого цветового кластера:
    
    - Для каждого цветового кластера создается маска, и с помощью функции `cv2.findContours` находят контуры.
    - Площади контуров меньше `MIN_AREA_CONTOUR` исключаются, чтобы избежать отображения слишком мелких деталей.
    - На каждом большом контуре с помощью функции `cv2.putText` наносятся номера соответствующих цветов, чтобы пользователи могли легко найти их в перечне.
7. **Сохранение и вывод результатов**  
    Итоговые изображения и перечень цветов:
    
    - **combined_image.jpg** — комбинированное изображение с основными и фоновыми цветами.
    - **blank_image.jpg** — контурное изображение с номерами цветов.
    - **colors.txt** — текстовый файл с перечнем RGB-кодов всех цветов, выделенных на изображении.

## Обратите внимание

Этот скрипт использует модель сегментации `DeepLabV3`, поэтому при первом запуске может потребоваться загрузка модели из Интернета.
